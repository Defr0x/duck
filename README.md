# НейроЧат 🧠

Сайт с регистрацией, входом, личным кабинетом (баланс + история транзакций)
и чатом с локальной нейросетью. Сделан по мотивам примера
[alexeykamalin/arch](https://github.com/alexeykamalin/arch), но доведён до
рабочего состояния: модель не роняет сайт при старте, пароли хранятся хэшами,
транзакции пишутся в базу, ошибки показываются в интерфейсе.

## Как запустить

```bash
pip install -r requirements.txt   # или: pip install flask mysql-connector-python python-dotenv
python app.py
```

Открыть http://127.0.0.1:5000

### Демо-режим без MySQL

Если база недоступна (нет интернета/хостера рядом), весь сайт можно поднять
на локальной SQLite — код приложения тот же, подменяется только подключение:

```bash
python demo_run.py
```

Демо-аккаунт: `demo@demo.ru` / `demo123`. База лежит в `demo.db`.
Нейросеть в демо-режиме отключена (иначе при первом сообщении полезет качать
модель).

## Подключение к базе

Доступы к MySQL лежат в самом коде — в `db.py`, переменная `DB_CONFIG`
(хост `185.114.247.43`, база `sch688_vvedenie`). Если сервер другой — правь
только этот словарь.

При старте сервер сам создаёт таблицы, если их нет:

- `users` — `id`, `username`, `email`, `password_hash`, `balance`, `created_at`
- `transactions` — `id`, `user_id`, `amount`, `type`, `cost`, `description`,
  `balance_after`, `created_at`

Старые пароли в виде SHA-256 (как в первой версии сайта) принимаются и
автоматически перезаписываются современным хэшем Werkzeug при входе.

## Нейросеть (локальная)

Чат работает на [llama-cpp-python](https://github.com/abetlen/llama-cpp-python)
с моделью `Qwen2.5-0.5B-Instruct-Q4_K_M.gguf` (репозиторий
`bartowski/Qwen2.5-0.5B-Instruct-GGUF`).

```bash
# 1. Ставим движок (сборка идёт несколько минут)
pip install llama-cpp-python huggingface_hub

# 2. Заранее скачиваем модель (~400 МБ) в папку models/
python download_model.py

# 3. Запускаем сайт
python app.py
```

Модель грузится в фоне при старте сервера: сайт открывается сразу, а в чате
видно состояние — «модель загружается…» / «модель загружена». Если движок или
файл модели не найдены, чат покажет подсказку, что доустановить, — остальной
сайт продолжит работать.

Необязательные переменные окружения (см. `.env.example`):

| Переменная   | Что делает                                   |
|--------------|----------------------------------------------|
| `MODEL_PATH` | путь к готовому `.gguf` (без скачивания)     |
| `MODEL_REPO` | другой репозиторий Hugging Face              |
| `MODEL_FILE` | другое имя файла модели                      |
| `SECRET_KEY` | ключ сессий (по умолчанию — из `app.py`)     |
| `HOST` / `PORT` | адрес и порт (по умолчанию 127.0.0.1:5000) |
| `FLASK_DEBUG=1` | режим отладки                             |

## Что умеет

- Регистрация с проверкой полей и вход по email/паролю (AJAX, без перезагрузки)
- Личный кабинет: имя, email, баланс
- Демо-пополнение баланса на 10–50 000 ₽ (виртуальные деньги)
- История транзакций: дата, сумма, описание, баланс после операции
- Чат с нейросетью: контекст последних сообщений, индикатор «печатает»,
  понятные сообщения об ошибках
- Выход из аккаунта

## API

| Метод | Адрес               | Назначение                        |
|-------|---------------------|-----------------------------------|
| POST  | `/api/register`     | регистрация (+ старый `/user_register`) |
| POST  | `/api/login`        | вход (+ старый `/user_login`)     |
| GET   | `/api/me`           | данные текущего пользователя      |
| POST  | `/api/topup`        | пополнение баланса + транзакция   |
| GET   | `/api/chat/status`  | готовность модели                 |
| POST  | `/api/chat`         | сообщение нейросети               |
| GET/POST | `/logout`        | выход                             |

Страницы: `/` (редирект), `/login`, `/register`, `/profile`, `/transactions`.

## Структура

```
app.py            — Flask: страницы и API
db.py             — доступы к MySQL и схема таблиц
llm.py            — загрузка локальной модели и генерация ответов
demo_run.py       — запуск на SQLite без MySQL
download_model.py — скачивание GGUF-модели
templates/        — base, вход, регистрация, профиль, транзакции
static/           — общие стили и скрипты
```

## Безопасность

- Пароли — хэши Werkzeug (PBKDF2), а не открытый текст
- SQL-запросы параметризованные, списание/пополнение — атомарными `UPDATE`
- Ответы модели и сообщения пользователя выводятся через `textContent`
  (без вставки HTML), поэтому XSS через чат не проходит
- `.env`, `demo.db` и `*.gguf` в `.gitignore`
